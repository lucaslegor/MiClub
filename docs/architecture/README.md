# docs/architecture

Documentación arquitectónica de MiClub SaaS orientada a la implementación.

- `adr/` — **Architecture Decision Records**: una decisión por archivo, con
  contexto, opciones consideradas y consecuencias. Numerar (`0001-...md`).

Las decisiones de producto/negocio de alto nivel siguen viviendo en `docs/01…10`.
Acá van las decisiones técnicas más finas que surjan durante el desarrollo.
